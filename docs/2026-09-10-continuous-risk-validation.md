# 연속 위험 로그 검증

## 출력과 해석

- 20초, 100Hz, 0~20초 포함 2,001행. 2초 사전 안정화 후 동일 물리 상태를 순차 적분한다.
- 정상 유지 / 정상에서 느린 전환 / 정상에서 빠른 전환. 같은 환경·예인 위치에서 비교한다.
- CSV 3개, SVG 3개, conditions.json 1개가 비교 ZIP에 포함된다.
- Sag ratio는 3D 처짐/직선거리, 변화율은 과거 샘플 차분(/s). 조향 입력과 실제 기하학적 각도를 별도 기록한다.
- IMU는 연속 궤적의 인접 자세로 계산한 이상적 합성값이다. 가속도 m/s², 각속도 rad/s, 모델 본체 좌표(+Y 위, +Z 선수)를 사용한다.
- 기존 위험 판정은 조향 입력 기반 모델 규칙이다. 합성 로그로 탐색한 임계값은 실측 검증이 필요하며 영상의 Sag 추정값과 동일하지 않다.

## 회귀 방지

연속 로그에만 명시적 처짐 값을 전달한다. 기존 실시간 모드와 이미지 데이터셋의 기본 줄 계산은 유지한다. 재생 중 기존 물리 적분을 멈추고 기록한 프레임을 표시하며 이미지 캡처와 동시 실행을 잠근다.

첫 requestAnimationFrame 타임스탬프가 performance.now()보다 이전일 수 있어 음수 인덱스가 발생했다. 인덱스를 0~마지막 프레임으로 제한했고 회귀 테스트를 추가했다.

## 확인 결과

- npm test: 65개 통과. 연속 시간 간격, 전환 속도별 변화율, 4방향 유한값, 연속 IMU, CSV·SVG 및 기존 데이터셋 회귀 포함.
- npm run build: TypeScript와 프로덕션 번들 생성 통과. 기존 대형 번들 경고는 남아 있다.
- 별도 코드 리뷰: 취소·완료 처리, 데이터셋 동시 실행 잠금, 재생 연동, 각도·차분·처짐 계산에서 차단 문제 없음.
- 브라우저에서 패널과 실행 버튼을 확인했으며 초기 재생 인덱스 오류를 수정했다. 이후 브라우저 연결이 시간 초과되어 수정 후 다운로드 UI 검증은 아직 완료되지 않았다.
