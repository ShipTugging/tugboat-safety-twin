# 시간 기반 위험 판단 V2 구현 계획

## 근거와 범위

사용자가 제공한 이제원 작성 2026-09-14 평가 보고서: YOLO26n-seg, 5,000 positive-only 합성 이미지, Test 500장/571 instances. Mask mAP50 0.918545, mAP50-95 0.637752. 원본 masks.xy polygon micro IoU 0.746484. Small(<500 GT pixels) 실패가 많다. 이 수치에서 실제 사고 위험 임계값을 도출하지 않는다. 현재 모델 SHA256 5223b140eabfbae514d94d7a5917450c8c76725efec4ba0c2a76914a5e07b456 유지.

조직 Vision 코드의 단일 class 0 최고 confidence 선택과 handoff의 timestamp_ms/vision/imu/sync 계약을 참고한다. 온라인은 원본 polygon 반올림 복원, conf .25, imgsz 960을 명시한다. 오프라인 handoff PNG는 복원·변형 없이 사용한다.

## 작업

1. Python 회귀 테스트: 고정 고신뢰도에서도 횡경사 위험 발생, 미검출을 Normal로 오판하지 않음, 단발 노이즈와 장기 누락, 시간 역전/간격, 회복 지연, Sag 변화율, 작은/분리된 마스크.
2. server/risk_engine.py: JSON 설정으로 관리하는 시연용 정책, 동일 이미지 좌표의 정상 기준각 학습, 시간 차분과 연속 확인, 근거·관측 상태·정책 버전 출력. 3D 실제 예인 각도라는 주장을 제거한다.
3. server/risk_geometry.py: 원본 마스크 연결 성분·골격·길이/분기/가림 품질 검사. 무효 geometry는 null, 신뢰도만으로 품질을 보장하지 않는다.
4. 기존 process_frame 및 synchronized.jsonl 진입점을 새 엔진으로 통일. sequence별 분리·동기화 실패 처리. 레거시 보정 각도는 진단용으로만 유지.
5. FastAPI: 모델 검증, 명시적 inference 설정, mask PNG 계약, 촬영 시각·프레임 ID·세션 ID 반환, 세션별 잠금/초기화, 잘못된 이미지 4xx, 원본 모델 유지.
6. 웹: 세션/촬영 시각 전송, UNKNOWN+IMU 위험 처리, 근거·Sag 변화율 표시, 서버 분석 중 운항값 조절 가능. 위치 변경은 새 관측 기준으로 세션 경계를 생성.
7. 실제 best.pt와 기존 선수 프레임 및 조직 handoff 480프레임으로 검증. 고위험 규칙은 합성 IMU/시간 시나리오로 별도 검증하고 실측 성능과 구분. 테스트·빌드·코드 리뷰 후 ShipTugging/tugboat-safety-twin에 push.

## 정책 가정

기본 IMU 시연용 기준은 |roll| 10/15/20도로 GirtingRisk/Developing/Critical 후보, 상승 롤 속도 2/5도/s와 |roll|>=5도 조합. 단발 peak를 막기 위해 0.3초/최소 2개 관측 확인, 정상 복귀 2초 지속. 비전은 초기 낮은 횡경사·낮은 각속도·안정된 1초 관측으로 기준각을 만들며 사전 기준 없이 실제 각도 threshold를 적용하지 않는다. Sag 속도는 최근 연속 유효 0.6초 구간의 선형 회귀로 계산한다. 모든 수치는 config와 응답에 정책 버전·시연용으로 표시하고 실제 선박 데이터로 재검증해야 한다.
