# 예인선 위치 확장

기존 선미 운항을 그대로 유지하면서 상선 주변의 선미·좌현·우현·선수 네 위치를 선택할 수 있게 확장했다.

## 동작

- 우측 `운항 파라미터 > 예인 위치`에서 네 위치를 선택한다.
- 위치별 상선 연결점: 선미 우현 쿼터, 좌·우현 중앙 외판, 선수 갑판.
- 조향각은 선택한 위치를 기준으로 예인선을 좌우로 선회시키는 미세조정 값으로 계속 사용한다.
- 예인선은 해당 연결점을 향하도록 기본 방위를 회전한다. 예인줄의 시작·끝점과 Sag 계산도 같은 좌표를 사용한다.
- 자유 시점은 위치 변경 시 두 선박의 중간을 다시 잡는다. 추적·선교·야간 투광등도 선택한 연결점을 향한다.
- 후류 판정은 실제 선미 뒤에서만 발생한다. 선체 이격·흡인력은 14m × 70m 선체 외곽의 가장 가까운 점을 기준으로 네 방향에서 계산한다.
- 위험 분석의 5m·9m 경계는 선체 전체를 둘러싼다.

## 호환성

`towPosition`이 없는 기존 프리셋·저장 상태는 `astern`으로 처리하므로 기존 선미 수치와 장면을 유지한다. 기존 네 위험 시나리오는 항상 선미를 명시한다. 후속 개선으로 Sag/객체 탐지 데이터 모두 현재 예인 위치·직접 지정·네 방향 혼합을 지원한다. 세부 검증은 `2026-09-09-dataset-positions-lens.md`를 참고한다.

## 검증

- 네 위치의 상선 연결점, 예인선 좌표, 기본 방위, 선체 이격 대칭성 테스트.
- 기존 선미 프리셋의 장력·거팅·후류·흡인 수치 회귀 테스트.
- 좌현·우현·선수에서 후류 오탐이 없고 연결점과 선체 거리가 유효한지 테스트.
- 브라우저에서 네 버튼, 자동 카메라 구도, 선수 추적 시점과 줄 연결 상태 확인.
- 레이더는 고정 선미 좌표 대신 현재 `lineStartPoint`를 사용한다. 텔레메트리·렌더링·데이터셋의 예인선 줄 끝점은 기울기까지 반영한 동일한 갑판 좌표를 사용한다.

한계: 현재는 네 구간 프리셋과 조향 미세조정 방식이다. 선체 둘레를 완전 연속 이동하거나 복수 예인선을 동시에 운용하는 기능은 포함하지 않는다.
