# 연속 위험 전환 로그

사용자 승인 범위: 동일 장면의 정상 유지 / 느린 정상→거팅 / 빠른 정상→거팅 시뮬레이션과 CSV 내보내기. 기존 데이터셋 기능 유지, 검증 후 GitHub push 및 배포.

## 구성

- 20초, 고정 100Hz, 기록 전 2초 안정화. 장면·예인 위치·환경 고정, 하나의 PhysicsState를 시간순으로 전진시킨다.
- 정상 5초 후 조향 12°→72°를 smoothstep으로 변화. 느림 10초, 빠름 1초. 속력 6kn/줄 길이32m/RPM45 고정으로 속도 비교의 교란을 줄인다.
- 실제 선체 방향과 예인줄 벡터의 각도를 별도로 계산해 기록. 기존 조향 기반 위험 엔진의 driver angle/status는 명시적으로 별도 열에 남긴다.
- 기존 하중 기반 처짐을 목표값으로 하고 시간상수0.3초의 연속 반응 적용. 렌더되는 줄과 CSV가 같은 처짐을 사용한다. 모델 기반 초기 임계값 분석용임을 데이터 설명에 기록한다.
- Sag ratio/인과적 변화율, 실제 각도/각도 변화율, 롤/롤 변화율, 장력, 6축 이상적 IMU, 모델 상태, 시나리오 단계.
- 생성 후 화면 재생, 중지·설정 복원, CSV 다운로드. 3종 비교 ZIP에는 CSV/SVG 그래프/조건 JSON 포함.
- 기존 무작위 데이터셋과 동시에 실행되지 않도록 잠금. 기존 Sag/렌즈/IMU 파일 포맷은 유지한다.

## 검증

- 시간 단조성·100Hz 간격·상태 지속·초기 과도 제거·실제 각도·빠름/느림 변화율 차이.
- CSV 열/단위·IMU 시각 일치·그래프 생성.
- 브라우저 실행/중지/CSV 및 비교 ZIP 다운로드·기존 데이터셋 회귀.
