# 예인줄 비전 모델 테스트 영상

## 목표

YOLO 실시간 연결 전에 사용할 20초, 1280×720, 30fps MP4. 기존 TUG_SAG_CAM과 선박·수면·예인줄 컴포넌트를 재사용하며 UI, 분할 라벨, 경고 효과를 영상에 합성하지 않는다. 모델 추론 결과가 아닌 시뮬레이터 원본 영상이다.

## 시나리오

| 시간 | 동작 |
|---|---|
| 0–5초 | 선수에서 36m 거리, 처짐 0.06m, 줄 팽팽한 안정 상태 |
| 5–10초 | 36m → 15m로 접근, 처짐 0.06m → 1.60m로 증가 |
| 10–15초 | 15m → 36m로 이탈, 처짐 1.60m → 0.06m로 감소 |
| 15–20초 | 선수에서 36m, 줄 팽팽한 안정 상태 |

선수 예인, 주간, 맑은 렌즈, 약한 파도. 예인 거리는 시뮬레이터의 선수 chock에서 측정하고, 같은 `nearFraction`으로 처짐을 계산한다. 가까워질 때 줄이 확실히 아래로 처지고 멀어질 때 팽팽해지는 시각적 관계를 시험하기 위한 영상이다. 수평 이동을 물리적으로 적분한 실선 항해 영상은 아니다.

## 생성

1. `node scripts/video-server.mjs` 실행.
2. `http://127.0.0.1:5177/scripts/video-capture.html` 접속 후 **20초 영상 프레임 생성** 클릭.
3. 600 / 600 완료 표시 확인.
4. `python scripts/encode-video.py` 실행. Python의 imageio-ffmpeg, Pillow가 필요하다.
5. `artifacts.local/towline-video-ahead/towline_ahead_distance_test_720p.mp4` 전달.

브라우저의 실제 렌더링 속도와 별개로 1/30초씩 순차 적분한 프레임을 H.264/yuv420p MP4로 인코딩한다. 영상 프레임은 JPEG만 저장하는 경량 경로를 사용하고, 정답 Sag는 프레임 메타데이터의 3D 렌더링 값으로 기록한다. 픽셀 마스크·YOLO 폴리곤은 영상 생성에 포함하지 않으며 기존 데이터셋 생성 기능에서 계속 제공한다. 저장 경로는 Git에서 제외된다. 로컬 서버의 쓰기 API는 루프백 주소의 동일 출처 POST와 제한된 프레임 번호만 허용한다. 기존 배포 UI와 데이터셋 기능은 수정하지 않았다.

## 검증

인코더는 모든 JPEG의 해상도, 600개 타임스탬프와 거리-처짐 순서를 검사한다. 완성 MP4를 다시 디코딩해 600프레임·30fps·20초·1280×720인지 검증하고 `video-validation.json`에 결과를 저장한다. 프레임별 메타데이터에는 선수 위치, 거리, 3D 렌더링 정답 Sag와 카메라 정보가 남는다. 픽셀 마스크는 일반 데이터셋 생성에서 별도로 확보한다.

2026-09-13 선수 예인 재생성 결과: H.264 MP4 600프레임을 다시 디코딩해 20.0초·30fps·1280×720을 확인했다. 예인 위치는 전 구간 `ahead`, 거리는 36m → 15m → 36m, 렌더링 정답 처짐은 0.06m → 1.60m → 0.06m로 확인됐다. 시뮬레이터 정답 Sag ratio 범위는 0.0018~0.1261이다. 0·5·10·15초 화면에서 선수 구도와 줄 가시성을 확인했다. 영상용 경량 캡처는 픽셀 마스크를 만들지 않으므로 YOLO 성능 검증은 별도다.
