# 예인줄 비전 모델 테스트 영상

## 목표

YOLO 실시간 연결 전에 사용할 20초, 1280×720, 30fps MP4. 기존 TUG_SAG_CAM과 선박·수면·예인줄 컴포넌트를 재사용하며 UI, 분할 라벨, 경고 효과를 영상에 합성하지 않는다. 모델 추론 결과가 아닌 시뮬레이터 원본 영상이다.

## 시나리오

| 시간 | 동작 |
|---|---|
| 0–5초 | 줄 처짐 0.08m, 조향 8°, 비교적 직선으로 안정 |
| 5–10초 | 조향 8→20°, 지정 예인 거리 26→28m로 완만하게 변화 |
| 10–15초 | 처짐 0.08→1.18m 증가 |
| 15–20초 | 조향 11°, 예인 거리 26m, 처짐 0.23m 방향으로 안정 복귀 |

선미 예인, 주간, 맑은 렌즈, 약한 파도. 기존 엔진의 선체 상하 움직임과 상대 위치 변화가 포함된다. 수평 이동을 물리적으로 적분한 실선 항해 영상은 아니다. 처짐은 감지 테스트를 위한 명시적 애니메이션이다.

## 생성

1. `node scripts/video-server.mjs` 실행.
2. `http://127.0.0.1:5177/scripts/video-capture.html` 접속 후 **20초 영상 프레임 생성** 클릭.
3. 600 / 600 완료 표시 확인.
4. `python scripts/encode-video.py` 실행. Python의 imageio-ffmpeg, Pillow가 필요하다.
5. `artifacts.local/towline-video/towline_test_720p.mp4` 전달.

브라우저의 실제 렌더링 속도와 별개로 1/30초씩 순차 적분한 프레임을 H.264/yuv420p MP4로 인코딩한다. 저장 경로는 Git에서 제외된다. 로컬 서버의 쓰기 API는 루프백 주소의 동일 출처 POST와 제한된 프레임 번호만 허용한다. 기존 배포 UI와 데이터셋 기능은 수정하지 않았다.

## 검증

인코더는 모든 JPEG의 해상도, 600개 타임스탬프, 매 프레임의 예인줄 가시 비율(최소 85%)을 검사한다. 완성 MP4를 다시 디코딩해 600프레임·30fps·20초·1280×720인지 검증하고 `video-validation.json`에 결과를 저장한다. 1초 간격의 정답 마스크와 프레임별 메타데이터도 로컬에 남긴다.

2026-09-13 생성 결과: H.264 MP4를 600프레임 모두 재디코딩했고 20.0초·30fps·1280×720을 확인했다. 전 구간 최소 줄 가시 비율은 90.77%, 처짐은 0.08~1.18m, 영상 기반 Sag ratio는 약 0.0050~0.0728이었다. 0·5·10·15초 프레임을 시각적으로 확인했다. 시뮬레이션 마스크 기준 검증이며 YOLO 성능 검증은 아직 아니다.
