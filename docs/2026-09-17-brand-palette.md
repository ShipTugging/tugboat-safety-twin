# 딥그린 테마와 로고 후보

## UI 팔레트

사용자 참조 이미지의 #071E07 / #0D330E / #2D531A / #477023 / #6E8649를 적용한다. 일반 글자는 #F5F7EB, 보조 글자는 #C6D5B5다. 밝은 올리브 위 글자는 #031003으로 더 어둡게 조정한다.

브라우저 computed style 기준 주요 대비:

| 항목 | 대비 |
|---|---|
| 선택 모드, 분석 시작 | 4.79:1 |
| 입력값 | 16.18:1 |
| 헤더 조작 숨기기 | 8.20:1 |
| 패널 일반 글자 | 12.95:1 |
| 패널 보조 글자 | 9.08:1 |

위험 단계는 구분 가능하도록 노랑·주황·붉은 경고색을 보존한다. 바다·배·YOLO 입력 영상에는 UI 색상 필터를 적용하지 않는다.

## 로고·파비콘 후보 (선택 전)

1. TENSION: 예인줄 곡선과 T를 결합한 심볼.
2. BOW: 위에서 본 선수와 중앙 예인줄을 표현한 기하학 심볼.
3. LINK: 예인선과 본선의 연결을 나타낸 맞물린 링크.
4. WATCH: 영상 감지 프레임과 예인줄을 결합한 심볼.
5. MONOGRAM: TG 글자와 파도 형태를 결합한 모노그램.

내장 imagegen으로 후보별 로고와 밝은/어두운 파비콘 프리뷰를 생성했다. 색상 요청 이후 후보 모두를 위 팔레트로 재편집한다. 미리보기 단계이며 선택 전 기존 로고와 파비콘을 교체하지 않는다.

공통 최종 프롬프트: 원래 후보별 심볼과 TUG GUARD 워드마크, 후보 번호, 두 파비콘 프리뷰를 유지한다. 배경 #071E07, 표면 #0D330E, 강조 #2D531A/#477023/#6E8649, 글자 #F5F7EB. 발광·그라데이션·블러를 제거하고 선명한 평면 형태와 대비를 확보한다.
