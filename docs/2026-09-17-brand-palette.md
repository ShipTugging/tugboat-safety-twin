# TENSION 브랜드와 최종 화이트 테마

## 최종 선택

사용자 선택은 후보 1 TENSION이다. 예인줄 곡선과 중앙 T 기둥, 양끝 원형을 SVG로 구성했다. 헤더 로고는 차콜 단색이며 파비콘은 흰 배경에 차콜 심볼을 사용한다. public/brand/tension-mark.svg와 tension-favicon.svg가 실제 사용 자산이다.

## 최종 색상

| 역할 | 색 |
|---|---|
| 배경 | #F7F8FA |
| 패널 | #FFFFFF |
| 제목·로고 | #202B33 / #252B30 |
| 보조 글자 | #596773 |
| 선택·분석 버튼 | #365E78 + 흰 글자 |
| 경계 | #DCE2E7 |

이 문서는 앞서 검토한 딥그린 팔레트를 대체한다. 예인줄 분리 버튼도 흰 바탕·청회색 테두리로 통일하고 경고·위험 상태에만 주황·빨강을 유지한다. 데이터셋, 로그, 상세 센서, 레이더·그래프의 UI 색도 함께 조정했다. 바다·선박·AI 입력 이미지의 색과 위험 계산 로직은 바꾸지 않았다.

## 검증

- 메인 1280×720 화면에서 로고, 핵심 수치, 예인줄 분리와 선택 버튼을 시각 확인.
- 추가 도구의 고급 조절, 서버 설정, 센서 탭에서 화이트 표면과 읽을 수 있는 글자색 확인.
- 로고·파비콘은 SVG여서 확대와 작은 탭 아이콘에 같은 형태 사용. 쿼리 버전으로 기존 캐시와 구분.
- 최종 빌드·기존 테스트 실행 후 배포.
