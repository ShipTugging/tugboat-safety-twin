# 시뮬레이터 업데이트 공유 (9/7)

노션에 올린 「1차 목표 제안」 읽고, 시뮬레이터를 그 방향에 맞게 손봤어요. 핵심은 **"예인줄이 팽팽한가?"를 영상으로 판단하는 모델을 학습시킬 데이터를 시뮬레이터가 자동으로 뽑아준다**는 거예요.

배포 주소: https://tugboat-safety-twin.vercel.app (우측 패널 → AI 데이터 생성 모드)

## 뭐가 바뀌었나

**1. Sag 5단계 라벨이 자동으로 붙어요**
노션에서 제안한 대로 Level 0(매우 팽팽함) ~ Level 4(매우 느슨함) 다섯 단계로 나눴어요. 기준은 `SagRatio = 최대 처짐 / 양끝 거리`이고, 렌더링되는 예인줄 곡선에서 직접 계산하니까 라벨이 틀릴 일이 없어요. 사람이 Label Studio로 칠할 필요 없다는 그 장점을 그대로 살렸습니다.

**2. 카메라 시점을 예인선에 고정했어요**
"예인선 안에서 towline과 상선을 바라보는 시점"으로 새 카메라를 추가했어요. 화면에서 `CCTV · 예인줄 감시(Sag)` 골라보면 됩니다. train/valid/test 모두 같은 구도로 뽑히고, 카메라 위치·각도는 살짝만 흔들어요.

**3. 로프 마스크가 픽셀 단위로 정확하게 나와요**
이미지마다 로프만 흰색으로 칠한 마스크 PNG가 같이 나와요. 선체나 물에 가려진 부분은 자동으로 빠집니다. YOLO-Seg 학습용 폴리곤 라벨도 따로 만들어져요.

**4. 환경 랜덤화 항목을 늘렸어요**
기존의 시간대·안개·파도·조명에 더해서 로프 색/두께, 상선 선체 색, 블러, 카메라 미세 회전까지 매번 바뀌어요. 같은 sag 단계도 다양한 환경으로 나오게 해서 과적합을 줄이려는 의도예요.

**5. 데이터셋 ZIP 구성**
```
images/   학습 이미지 (960×540 JPEG)
labels/   YOLO-Seg 폴리곤 라벨 (클래스 0~4 = sag 단계, 5 = 상선 선미)
masks/    로프 픽셀 마스크 PNG
data.yaml Ultralytics 학습 설정 (바로 yolo segment train 가능)
sag_labels.csv  프레임별 단계·SagRatio·장력 표
```
100장 기준 5장 단위로 단계가 균등하게 섞여 나와요. 학습용/검증용은 시드 다르게 두 번 뽑으면 됩니다.

**6. 화면에도 sag 정보가 보여요**
3D 화면 왼쪽 아래에 현재 예인줄의 단계와 비율이 뜨고, 센서 탭에 "예인줄 Sag 파이프라인" 카드를 넣었어요. 데모 영상 찍을 때 쓰기 좋을 거예요.

**7. 마스크 → SagRatio 계산 스크립트**
`scripts/sag_from_mask.py`가 노션 공식대로 마스크에서 중심선을 뽑고 SagRatio를 계산해요. 나중에 모델이 예측한 마스크를 여기 넣으면 그대로 sag 값이 나오는 구조예요. `--compare` 옵션으로 시뮬레이터 정답과 비교도 됩니다.

## 확인해본 것

- 헤드리스 브라우저로 실제 ZIP 뽑아서 검증 스크립트 돌렸어요. 5단계 골고루 나오고, 폴리곤 라벨과 픽셀 마스크가 잘 겹치고(IoU 0.86), 마스크로 계산한 SagRatio도 정답과 거의 일치했어요.
- 단위 테스트 39개 통과, 기존 박스 탐지 데이터셋도 그대로 동작해요.

## 참고 / 다음 할 것

- 3D 기준 SagRatio와 영상에서 보이는 SagRatio를 둘 다 기록해요. 원근 때문에 영상 쪽 값이 더 크게 나오는데, 클래스(단계)는 3D 기준으로 붙였어요.
- 아직은 정지 프레임만 뽑아요. 노션에서 말한 "프레임 단위로 빠르게 팽팽해지는지" 보려면 시간축 시퀀스 캡처가 필요한데, 그게 다음 단계로 좋을 것 같아요.
- 시뮬레이터 데이터로만 학습하면 실제 영상과 차이가 있을 테니, 본선 가서 실제 클립으로 검증하는 건 여전히 필요해요.

자세한 설계 내용은 `docs/2026-09-07-towline-sag-dataset.md`에 정리해뒀어요.
