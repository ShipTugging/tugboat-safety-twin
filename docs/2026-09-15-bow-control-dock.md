# 선수 기준 시연 도크

## 목표

서버 응답과 주요 운항값을 오른쪽 패널을 스크롤하지 않고 함께 확인하고, 드래그 없이 시나리오를 조절한다. 기본 화면은 선수 예인과 선수 CCTV로 시작한다.

## 화면 구성

- 하단 시나리오 카드 아래에 `선수 기준 상세 설정`을 항상 표시한다.
- 예인 위치는 선수·선미·좌현·우현 버튼으로 선택한다. 선수 버튼을 첫 번째로 두고 초기값을 선수로 지정한다.
- 카메라 선택, 조향각, 예인줄 길이, 본선 속력, 추진기 RPM을 숫자 입력과 단축값 버튼으로 제공한다.
- Python / YOLO-Seg 요약 행에 주소, 연결 상태, 서버 판정, 융합 모드, 신뢰도, Sag, 롤과 연결·초기화 버튼을 배치한다.
- 기존 오른쪽 상세 관제 패널과 운항 파라미터는 유지한다. 도크는 반복 조작용이고 상세 패널은 전체 결과 확인용이다.

## 상태와 안전

데이터셋·연속 로그가 실행 중이면 도크의 운항값을 잠근다. V2 서버 분석 중에는 운항값·비상 분리를 조절하며 결과를 확인할 수 있다. 서버 주소는 연결 중 잠긴다. 서버 응답의 `UNKNOWN`은 `관측 불가`로 표시한다. 서버 판정과 Three.js 물리 관측값은 서로 다른 출처이므로 섞지 않는다.

## 검증

1440×1000 로컬 브라우저에서 선수 CCTV와 하단 도크가 한 화면에 보이는 것을 확인했다. 조향각 85°, 예인줄 36m, 본선 속력 14kn, RPM 80을 단축 버튼만으로 적용했고 화면 값과 물리 위험도 100% 갱신을 확인했다. 실제 Python 서버 연결 상태·서버 결과·CCTV 입력도 동일 화면에 표시됐다. 숫자 범위 보정과 선수 기본값 테스트를 추가했다.
