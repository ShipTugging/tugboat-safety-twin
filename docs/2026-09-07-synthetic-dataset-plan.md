# 합성 데이터 파이프라인 구현

사용자 명세에 따라 구현·GitHub 푸시·기존 Vercel 재배포까지 수행한다.

## 구성

- 기존 레이아웃의 우측 패널에 AI 데이터 생성 모드, 장수(기본 100), 시드, 시작/취소/다운로드를 통합한다. 장면의 홍보성 문구를 제거한다.
- 화면과 캡처가 같은 물리 계산을 사용하도록 현재 엔진을 순수 함수로 분리한다. 캡처는 별도 상태로 충분한 가상 시간 동안 안정화하며 라이브 제어를 일시 잠근다.
- 캡처 샘플을 React에 반영한 후 실제 R3F 프레임의 마지막 단계에서 렌더→JPEG→Box3 투영을 연속 실행한다. 이미지는 Canvas만 포함하며 UI/위험 표시의 정답 누출을 막는다.
- near/far 평면과 화면 경계를 처리한 YOLO 박스. 0 예인선, 1 팽팽한 줄, 2 처진 줄, 3 선미. CCTV 자신의 예인선은 제외한다. 부분 가림은 투영 AABB 라벨 정책을 metadata에 명시한다.
- CatmullRom 곡선 및 라벨이 같은 장력 분류 함수를 사용한다. 고장력 320kN 이상 또는 CRITICAL은 taut, 나머지는 slack. 분리된 줄은 라벨에서 제외한다.
- normal map 기반 물결, FogExp2 해무, 45RPM 이상 거품 및 115RPM에서 방출량/크기 2배. 두 CCTV는 선박의 실제 변환을 따른다.
- ZIP: images/frame_0001.jpg, labels/frame_0001.txt, classes.txt, metadata.json. 파일명·라벨 일치, 제한된 메모리, 취소/오류 시 상태 복원. 학습/검증 분할은 독립적인 시드의 별도 캡처를 사용한다.
