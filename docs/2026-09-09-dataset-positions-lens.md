# 전방향 데이터셋과 물 튐 렌즈

## 원인과 변경

Sag 생성기의 `towPosition: astern` 하드코딩으로 운항 위치와 캡처 위치가 달랐다. 생성기에 위치를 전달하고, Exporter가 시작 시 현재 위치/선택 위치를 복사해 작업 전체에 적용하도록 수정했다. Sag와 객체 탐지 모두 동일한 선택 규칙을 사용한다.

- 기본: 현재 예인 위치. 직접 선미/좌현/우현/선수 선택 또는 혼합 가능.
- 혼합은 `index % 4`, Sag 단계는 `index % 5`로 구성해 20장마다 모든 조합을 포함한다.
- Sag CCTV는 실제 줄 양끝점으로 프레이밍한다. 자유 캡처 카메라도 선택 방향에서 배와 줄을 향하며 화면 범위를 자동 조정한다.
- 선미 클래스는 기존 의미를 유지한다. 선수/현측에서 실제 선미가 안 보이면 선미 라벨을 억지로 붙이지 않는다.

## 물 튐 / 흐림

렌즈 상태를 맑음/흐림/물 튐/자동 혼합으로 선택한다. 혼합 상태는 Sag 단계나 예인 위치와 별도로 난수를 뽑는다.

- 맑음: 전역 blur 0, 물방울 없음.
- 흐림: 전역 Gaussian blur 1~4px.
- 물 튐: 0.3~1.5px 전역 blur, 시드 기반 물방울의 국소 blur와 가장자리 반사광. 젖음 강도 0.35~1.
- 후처리는 RGB JPEG에만 적용한다. 공간 이동/왜곡은 하지 않아 마스크·폴리곤·Sag 좌표가 유지된다. `visibleFraction`은 기하학적 가림 비율이며 물방울을 통한 광학적 식별성을 의미하지 않는다.
- 렌즈 상태, blur 크기, 젖음 강도, 물방울 시드는 JSON과 CSV에 기록한다.

## 검증

- 테스트 52개 통과: 위치 선택, 네 위치 각각 50개 Sag/FOV 표본, 렌즈 조건·시드 재현성, 기존 물리/캡처/마스크 검사.
- 브라우저 네 방향 혼합 40장 생성: 각 방향 10장, 각 Sag 단계 8장. 마스크·이미지·YOLO-Seg 페어와 좌표 검증 통과.
- 실제 ZIP 폴리곤/마스크 IoU 평균 0.8707, 최소 0.8071. RGB의 흐림과 물방울도 검토용 이미지에서 확인했다.
- 실제 선수 위치 선택 후 `현재` + `물 튐`으로 5장 캡처: 전부 ahead/wet, L0~L4 각 1장, 마스크 검사 통과(IoU 평균 0.868).
- 객체 탐지에서도 네 방향 혼합 + 흐림 12장 ZIP의 이미지/라벨 검증 통과. 브라우저 WebGL/JavaScript 오류 없음.
- 라벨은 깨끗한 기하학적 정답이다. 실제 물방울의 굴절 왜곡이나 실제 학습 성능 검증을 구현한 것은 아니다.

문서와 소스만 Git에 포함하며 테스트 ZIP/미리보기와 .env·인증정보는 업로드하지 않는다.
