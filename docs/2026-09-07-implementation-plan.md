# 해양 관제 디자인 구현 계획

승인 근거: 디자인 검토 후 사용자의 구현 요청(“해줘”).

목표: 선박 두 척과 예인 관계가 보이는 해양 장면, 겹침 없는 관제 UI, 절제된 위험 표시.
구조: 기존 React/Three.js와 물리 상태 인터페이스를 유지하며 표시 컴포넌트를 개선한다. 외부 모델/키/신규 런타임 의존성 없이 절차적 재질과 기존 형상을 개선한다.

- [x] 화면: App/Dashboard/Scene3D의 고정 분할과 absolute 겹침을 교체. 상단 브랜드/상태, 넓은 장면, 우측 스크롤 패널, 상시 비상 조작. 좁은 화면에서는 상하 흐름.
- [x] 바다: OceanWater의 좌표/법선/시선 기준 통일, 시간대별 반사와 낮은 항만 파도. 선박 주변 포말을 같은 수면에 합성하여 평면 겹침 제거.
- [x] 선박: LargeShip/Tugboat 재질·형상 개선, 개별 컨테이너/갑판 디테일. 단위와 연결점 유지. 별도 에이전트가 두 파일만 담당.
- [x] 장면: HarborEnvironment 배경 부두/크레인, 카메라 기본 구도, 품질 단계. 위험 표시를 작고 선택적으로 제공.
- [x] 회귀: 기존 물리 검사와 빌드 기준 기록. 예인줄 Hook 순서 수정. 실제 브라우저에서 시나리오/분리/복귀/시간대/카메라/모바일 확인.
- [x] 마무리: 독립 코드 리뷰, README와 트러블슈팅 최신화. 배포 전 로컬 프리뷰 제공.

검증: npm run test:physics, npm run build, 브라우저 1280×720/1440×900/390×844. 기존 물리 검사는 계산 복사본을 테스트하므로 실제 앱 시나리오 점검을 병행한다. 성능 숫자는 측정하지 않은 값을 표시하지 않는다.
