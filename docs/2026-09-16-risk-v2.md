# 위험 판단 V2: 보고서 반영, 알고리즘, 검증

## 반영한 평가 보고서

이제원 작성 2026-09-14 Dataset V2 / YOLO26n-seg 최종 평가 보고서를 사용자로부터 전달받았다. Test 500장/571 instances, Mask mAP50 0.918545, mAP50-95 0.637752, original polygon micro IoU 0.746484. Positive-only 집합의 returned-mask rate 99%는 일반 정확도 또는 실제 사고 예측 성능이 아니다. Small GT(<500 pixels)의 mean IoU 0.5326 및 실패 집중을 품질 검사 필요성의 근거로 사용했으며, 사고 위험 임계값의 근거로 쓰지 않았다.

체크포인트는 수정하거나 재학습하지 않았다. 저장소 모델 SHA256: `5223b140eabfbae514d94d7a5917450c8c76725efec4ba0c2a76914a5e07b456`. 보고서에는 Drive 체크포인트의 해시가 없어 동일성을 추가 인증했다는 의미는 아니다.

조직의 `tugboat-safety_vision`은 class 0 최고 confidence 선택을 구현하고 있었고, 보고서는 pixel 평가에서 모든 polygon 합집합을 사용했다. 런타임은 **class 0 최고 confidence, 동점은 첫 prediction**으로 명시한다. 보고서의 집계 단위와 다르다. 여러 instance가 있다고 별개 줄을 임의로 하나로 연결하지 않는다. instance 개수와 선택 번호를 반환한다.

## 바뀐 판단

- `imgsz=960`, `conf=0.25`, `retina_masks=False`, `masks.xy` 원본 좌표를 `np.rint`로 반올림하고 `cv2.fillPoly`로 0/255 PNG 복원.
- 선택된 mask에서 연결 성분과 8-neighbor skeleton 경로를 계산한다. 큰 연결 성분 비율, 분기, 짧은 chord, 화면 경계 잘림, 작은 mask, 낮은 confidence를 검사한다. 품질이 부족하면 Sag/각도를 null로 반환한다.
- Small 검사는 **예측 foreground 면적을 720p로 환산한 500px** 휴리스틱이다. 보고서의 GT 크기 판정과 같지 않으며, 품질 검사 통과가 높은 IoU를 보장하지 않는다.
- 화면 수직 기준 무방향 각도(180도 주기)의 초기 저운동 기준을 1초/최소 5관측으로 수집한다. signed angle에 절댓값을 두 번 적용하지 않고 modulo 180 최단 편차를 쓴다. 물리적 선수 방향을 mask만으로 판정하지 않는다.
- 기존 gamma/3D 각도 보정은 위험 판단에서 제거했다. `towline_angle_corrected_deg=null`로 남겨 기존 JSON 필드를 유지한다. camera calibration 없이 실제 3D 예인각을 복원했다고 표시하지 않는다.
- Sag 변화율은 연속 유효 관측 0.6초 구간의 시간-선형 회귀 slope(/s). 최소 3점/0.2초가 필요하고 누락 또는 1초 초과 간격 이후 새로 수집한다. Sag는 줄 장력(kN)이 아니다.
- IMU 롤·롤 속도는 모든 융합 모드에서 평가한다. confidence가 높다고 큰 횡경사를 무시하지 않는다. 상승 롤 속도는 roll과 roll_rate의 부호가 같은 경우만 사용한다.
- 경보는 각 단계 이상의 증거가 0.3초/최소 2관측 지속되어야 확정한다. Developing/Critical 경계를 오가도 최소 Developing 증거는 누적한다.
- 경보 하향은 **도착할 단계**가 2초 연속 유지되어야 한다. 중간 단계의 회복 시간을 Normal 프레임 하나가 물려받지 않는다.
- 영상 미검출/품질 저하는 `observation_status`로 별도 표시한다. 확인된 위험이 없다면 UNKNOWN, IMU 위험이 확인되면 Critical 등의 위험 상태와 미검출을 함께 반환한다. 관측 상실만으로 확인된 위험을 해제하지 않는다.

## 시연용 정책

`server/risk_policy.json`에 버전·출처·임계값을 저장한다. `TUGGUARD_RISK_POLICY`로 다른 정책 파일을 지정할 수 있다. 이는 합성 시나리오를 위한 설정이며 선박별 복원성/실측 사고 데이터로 검증한 값이 아니다.

| 조건 | 후보 상태 |
|---|---|
| 유효 영상 Sag <0.05 | Loaded |
| Loaded이며 Sag 변화율 ≤-0.05/s | GirtingRisk |
| Loaded이며 초기 영상 각도 편차 ≥30° | GirtingRisk |
| 편차 ≥56°, Loaded, abs(roll) ≥10° | Developing |
| abs(roll) ≥10 / 15 / 20° | GirtingRisk / Developing / Critical |
| abs(roll) ≥5°이며 더 기우는 속도 ≥2 / 5°/s | GirtingRisk / Developing |

정책값과 실제 충족 조건을 응답 `thresholds`, `reason_codes`, `candidate_state`로 확인한다. `risk_state`는 확정된 상태, candidate는 시간 확인 전 후보다. 큰 횡경사 규칙은 거팅 원인을 확정하는 분류기가 아니라 IMU 이상 경보다.

## 서버와 프론트 계약

POST /analyze는 JPEG/PNG와 **필수** roll_deg/roll_rate_deg_s를 받는다. session_id, frame_id, captured_at_ms, camera_context를 추가로 받으며 응답에 그대로 돌려준다. captured_at_ms 또는 timestamp_ms를 기준으로 계산하고, 둘 다 있으면 일치해야 한다. 누락된 구버전 시간은 서버 monotonic arrival로 처리하며 `timestamp_source=server_arrival_legacy`로 표시한다. 한 세션 안에서 clock 종류 변경/중복·역순 시각은 409.

온라인 IMU는 해당 이미지와 같은 시점이라는 클라이언트 계약을 전제로 한다. 외부 하드웨어의 실제 동기화 정확도를 서버가 검증했다는 의미가 아니다. 오프라인 canonical JSONL은 `sync.matched`와 |time_delta_ms|≤50ms를 확인한다. sequence_id별 이력을 분리하고 불일치 경계를 거부한다.

세션별 classifier와 요청 잠금, 최대 64개 세션·30분 유휴 만료. 모델 predictor 접근은 직렬화한다. POST /reset의 session_id로 해당 세션만 초기화한다. 이를 인증/권한 분리로 해석하면 안 된다. 배포 인증은 별도 범위다.

프론트는 UUID 세션과 촬영 시각을 전송하고 응답 ID/시각을 검사한다. 실제 mask를 녹색으로 겹쳐 표시하고, 품질·판정 근거·Sag 변화율·기준각 편차를 보여준다. 분석 중에도 조향·속력·비상 분리를 조절할 수 있다. 예인 위치/캡처 mount 설정 변경은 영상 기준을 재수집한다.

## 검증 결과

- 기존 체크포인트 해시 유지. 실제 모델/HTTP로 선수 영상 60프레임 paired replay: Loaded 49, Normal 11, geometry valid 60, 중앙 왕복 150.13ms. 첫 요청 포함 최대 3703ms.
- 같은 RGB에 **명시적으로 합성한 스트레스 IMU**를 넣은 60프레임: Loaded 24, GirtingRisk 10, Developing 5, Critical 21. 중앙 왕복 160.98ms. 이 시험은 사고 정답 데이터 평가가 아니다.
- 흰색 무관 영상: 최초 UNKNOWN, 큰 횡경사를 지속 입력하면 미검출 상태와 Critical 동시 반환. 실제 no-towline 영상의 일반적인 오탐률 평가는 아니다.
- 조직 handoff의 canonical synchronized.jsonl 480프레임 처리: 오류 없이 Loaded 214 / Normal 266. 마스크는 전달된 PNG를 그대로 사용. upstream retina 경로와 온라인 polygon 경로를 동일 pixel 평가라고 주장하지 않는다.
- 브라우저에서 **선수** + 조향 85° + 속력 14kn 변경 시 실제 모델 + 시뮬레이션 IMU 경로로 Developing→Critical 확인. confidence가 0.99여도 경계 잘림·분기 품질 경고를 내고 IMU 우선 판단. 실제 예측 마스크 overlay 확인.
- 회귀 테스트: 지속 경보, 단발 spike, 단계 흔들림, 회복 시간, 미검출, 작은/분리 mask, 시간 역전/누락, session reset 격리, polygon 반올림/PNG, canonical sync 실패.
- Python 15개 테스트와 프론트 94개 테스트 통과. 코드 리뷰에서 찾은 단계 흔들림/회복 시간 두 문제를 재현 테스트로 수정했고 후속 리뷰에서 추가 차단 문제 없음. Vite 빌드 확인. 실제 YOLO runtime은 Ultralytics 8.4.152, PyTorch 2.14.0+cpu로 보고서의 T4 평가 환경과 다르다.
