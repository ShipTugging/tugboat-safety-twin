# 시연 UI 개선 검증 기록

- 배와 예인줄 장면을 확대하고 오른쪽에 핵심 조작·분석을 배치했다.
- 1280×720: 장면 920×660, 기본 패널 clientHeight=660 / scrollHeight=660.
- 1920×1080: 기본 패널 clientHeight=1020 / scrollHeight=1020.
- 390×844: 장면 위·패널 아래로 배치, 세로 스크롤 허용.
- 화면 설정 버튼: 열기 전후 x=812, y=667.5, width=90, height=34.5로 동일. 동일 버튼으로 닫기 확인.
- CCTV 이름이 선택창 안에서 잘리지 않음. 조작 숨기기 후 카메라·시간대·설정 컨트롤이 숨고 같은 위치의 조작 표시로 복원.
- 실제 best.pt Python 서버 응답에서 줄 팽팽함, 영상+기울기 센서, 원본 CCTV와 녹색 예측 마스크 표시를 확인.
- 모델 첫 추론 및 빌드 동시 실행 중 5초 타임아웃 발생. 기존 타임아웃 정책을 변경하지 않았으며 오류·마지막 결과·재연결 UI 확인. 준비된 모델에서 이후 약 101~246ms 응답 확인.
- 추가 도구에서 기존 예인 위치·프로펠러 속도·레이더·센서·데이터 생성·연속 로그·JSON 기능 진입점 보존 확인.
- API 코드·체크포인트·물리·위험 임계값은 변경하지 않음. 한국어 표시만 변경.
- React 검토: 기존 서버 훅 공유, 추가 분석 루프 없음, dialog 기본 포커스/닫기 처리, 타이머 cleanup, 마스크와 이미지 16:9 정렬.
- 민감 환경 파일과 서버 모델·가상환경은 Vercel 업로드에서 제외.

- 최종 npm test: 95개 통과. npm run build 통과. 기존 큰 번들 경고는 유지. 위험 전환·분리·회복 전체 시나리오와 데이터셋 전체 생성은 이번 UI 작업에서 재실행하지 않았다.

## 배포 문제 해결

첫 Vercel 배포에서 제외 패턴 server/가 src/server/protocol.ts까지 제외하여 TypeScript 빌드가 실패했다. 루트 기준 /server/로 수정해 Python 서버만 제외하고 프론트엔드 API 모듈을 포함한다.
